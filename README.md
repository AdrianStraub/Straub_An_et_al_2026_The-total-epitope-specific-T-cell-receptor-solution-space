# The epitope-specific T cell receptor solution space utilizes the entire set of germline-encoded V(D)J genes
This repository contains the code to reproduce the results from the manuscript **The epitope-specific T cell receptor solution space utilizes the entire set of germline-encoded V(D)J genes**.

Please download the supplementary data and extract them into `tcr_data` and follow the instructions within the notebooks 01-03*, or if you are interested in the specificity predictor, follow the README inside `TCRprediction`.
